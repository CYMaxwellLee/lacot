## 三、設計（三個零件）

### 零件1：行為字典 v0（TAP 式起點、最小改動）
- encoder 輸入：現行 4 步 action 段 → 改 **(s_{t:t+4}, a_{t:t+4}) concat**（先保 chunk=4 與現行量尺可比；H=15 TAP 檔位放第二步掃）。
- 量化：**單本 VQEMA**（回到 u 已證會學的單本；G×K 平行頭病不帶入 v0）。K 掃 {32, 512, 8192}——32 對照現行、512/8192 抄 H-GAP/TAP。
- decoder：輸入（碼嵌入, s_t）→ 輸出 **(â_{t:t+4}, ŝ_{t+1:t+5})**（動作＋狀態流，主人裁的「後者」）。loss = recon_a + λ_s·recon_s + commit；λ_s=1.0 起，λ_s=0 留作消融臂。
- 訓練：現行 pipeline、50k 步、分鐘級/顆。

### 零件2：段級閉環 u（主人④的段級版）
- 序列 = (路標, s摘要_0, 碼_1, s摘要_1, 碼_2, …)——**實走 state 摘要 token 交錯進上下文**；訓練時＝教材真 state（免費），部署時＝實走 state。
- s 摘要 token＝小 MLP 連續投影（state 是條件不是預測目標；u 只預測碼——不給 u 加 state 預測頭）。
- 半路增強（4 刀）照搬：切點 state 當教材起點——治「教材 state 流全乾淨、部署歪掉 OOD」的已知病（robust_decoder 病型再現的預防）。

### 零件3：閉環執行（空白格①的實作）
- decoder 隨碼解出 ŝ 參考流；執行時逐段量 |s_actual − ŝ|。
