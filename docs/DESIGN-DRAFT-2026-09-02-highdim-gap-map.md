# 高維缺課地圖（起點頁，跟主人一起敲用；不是設計稿、不先實作）

問題：maze 的死區熱圖靠 2D 格子加模擬器。高維（antmaze 約 29 維、humanoid 約 69 維、手臂）
格子爆炸、歐氏距離失義，「模型哪裡不會」不能用掃空間得到。

主人給的方向（9/1 晚）：看 manifold 上 sample 的分佈、OOD／energy 那族、metric learning 技巧、
能量 coverage 的東西。

ルナ的起點直覺：不掃空間、沿分佈量。只要兩個一維分數：
- coverage 缺口：資料點在模型分佈下的 NLL（模型會不會生它）。引擎自帶 exact likelihood，
  但要在表示空間用，不能在原始空間用（Nalisnick 那條線：NF 常給 OOD 更高的 likelihood）。
- precision 缺口：模型自己的樣本離資料流形多遠（表示空間的 kNN 距離，Sun 2022 那招）。
兩個分數都是「每個點一個數」，維度再高也只是 N 個點各一個分數，量測永遠發生在重要的地方。

要一起決定的四件事：
1. 空間：在哪個表示空間量？候選：e_target 的 contrastive 空間／quasimetric（時間可達性）／
   encoder 的 u 空間。判準：那個空間裡「近」要等於「容易到達」。
2. 缺課度的粒度：per-sample 分數可以直接當出題權重與劑量（不用聚類）；per-region 才有地圖可看。
   可能兩層：per-sample 管劑量，聚類只管可視化與人看。
3. 校準：怎麼知道分數對？maze 是校準場（有 2D 真相：死區熱圖、密度 1/3 vs 1/7）。
   先在 maze 上驗「分數高的區域就是失敗聚集的區域」，驗過才帶去高維。
4. 停藥條件：缺課度不降即停（v3 自動停藥）。dz3 翻車就是沒有停藥條件、也沒有隨模型變的出題器。

今早新增的一手證據：三輪荒漠出題的權重完全相同（只看資料密度），模型進步了也還在教同一章。
這是「缺課度取代密度」最直接的動機。

不做的事：不先實作、不掃全空間、不在原始空間用 NF 密度、不拿沒抽原文的番號進設計文件。

文獻抽查清單（引用前抽原文）：Naeem 2020 Density&Coverage、Kynkäänniemi 2019 improved P&R、
Liu 2020 energy OOD、Sun 2022 kNN OOD、Nalisnick 2019。

## 9/2 白天新增的一手證據（設計要吃進去）

1. 荒漠有兩種尺度：出題器的粗格（迷宮格）看到覆蓋率 1.000、零資料格 0；細格（2 單位）看到 (13,15) 那格
   六千多點、東南象限 0 點，而低分顆的 task3 全死在那個角落。⇒ 缺課地圖的解析度要比出題器細，
   或者直接用「每個樣本一個分數」（kNN 距離／NLL）而不是格子。高維本來就沒有格子可用，這一點反而一致。
2. 失敗地理兩種：零資料口袋（共通、真荒漠、占 9%~36%）與高密度路口（各顆不同、占多數、不是缺資料）。
   ⇒ 缺課地圖只治得了第一種；第二種是執行通道不讀 u（BC 0.000、null_u 0.18），要從訓練方差下手（C 批）。
   設計時別把兩種混成一張圖。
3. 量測尺：死點的資料密度分位（校準：靠牆格中位 0.38、內部格 0.81）是 maze 上可用的「荒漠儀」；
   高維版要能在表示空間算出等價的東西（kNN 距離的分位）。校準流程：先在 maze 上驗「分數高的地方＝死點聚集處」。
4. 同 ckpt 重評雜訊 ±0.03：任何「補課有效」的宣稱都要跨過這條線、而且要多顆。
