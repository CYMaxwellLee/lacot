# 工單 A1：教師編碼四格 swap（a 題首刀）

**在證明什麼、判準是什麼**：證明「E(τ) 教師碼帶路線資訊、且 action head 會跟隨」——
判準（預註冊）：定向差 S_c 在配對 bootstrap 95% CI 下 > 0〔拍〕（head 動作與碼所屬
路線的合法決策一致率，swap 後跟碼走而非跟條件走）；第 0 步關卡：合格分岔對 n ≥ 30
〔拍〕，不足即停下回報改題（⛔ 不硬跑小樣本）。

〔拍〕門檻跑前寫死，回填新舊並排（主人裁③）。

## 設計（來源：CONVERGENCE 題 a 首刀；opus-a C1 × astra2-a 放大）

第 0 步（路線標記＋計數，先交數字再開下一步）：
- 官方 val 上以 BFS 找「同 (s,g) 存在多條幾何不同短路」的迷宮格局；在教材裡找
  覆蓋不同路線的軌跡對 (τ_A, τ_B)（條件相近、實走路線不同）。
- 路線標記用走廊序列（迷宮格 id 序列去重），不用逐點座標。
- 交付：合格對 n、路線多樣性分布。n < 30 ⇒ 停，回報（出口：放寬「條件相近」尺度
  或改用合成分岔起點 —— 那要另裁，⛔ 別自行升級）。

四格主測（n 過關才跑）：
- c = cond(s,g)、e = E(τ) 教師碼（凍結 encoder 跑真軌跡）。
- 四格：H(c_A,e_A)／H(c_A,e_B)／H(c_B,e_A)／H(c_B,e_B)——H = action head 前傳。
- 主讀數 S_c ＝「動作與 e 所屬路線一致」的定向差：swap 格裡 head 跟 e 走＝碼在
  指揮；跟 c 走＝碼是裝飾。
- 評分用**合法下一步集合**（BFS 多條同長最短路時，任何合法選擇都算對；⛔ 不拿
  tie-break 當唯一答案）。
- ckpt：recon_ictr（sg_infonce 那顆只作歷史對照，⛔ 不進主表 —— 它的目標不要求
  帶路線）。

讀頭對照（同批便宜加做，astra2-a C4 放大——全部用已訓好的頭，零新訓練）：
同一批題比四條：bc_head(cond)／ahead(cond, E(τ))／ahead(cond, F(cond,0))／
ahead(cond, F(cond,ξ))。T=0 稱「base 零點逆像」⛔ 不稱條件均值。
讀數：E(τ) 條大幅贏 bc_head ⇒ 教師碼有實用資訊；F(cond,·) 兩條若不贏 ⇒ flow
供給病（配合四格讀數定位——合併讀數表見 CONVERGENCE 題 a）。

## 資源與自檢

- 規模：n×4 前傳 ＋ 讀頭四條 —— 分鐘-小時級，zeldajr 本機或 2080ti 台皆可。
- 注意：BoN raw JSON 沒存 latent/軌跡 ⇒ 需要的中間量全部重播凍結推論取得。
- 接線自檢（兩向）：正向 —— H(c_A,e_A) 動作與 τ_A 路線一致率顯著高於隨機；
  負向 —— e 換全零向量，一致率必須塌向隨機。完成錨：輸出寫 n_pairs/n_cells。
