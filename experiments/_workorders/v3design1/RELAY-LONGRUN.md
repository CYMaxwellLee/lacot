# 接力棒長跑（F6 設計稿 v1；主人 2026-09-28 系列裁示合成、⏳ 待 S2 審查＋主人終裁）

_在證明什麼：無人看管的多小時自主推進可以「不退化成密度農場、不因平台限制塌掉」。
判準：首航（一個過夜實驗管理夜）做到——零樹外行動、加密度算力 ≤20%、每棒交接
可回放、審計三問全有證據、醒來 lead 十分鐘內從狀態檔重建全夜。_

## §1 為什麼是接力不是馬拉松

Anthropic 九迴圈=單 agent 長跑一週（模型單體強撐；黑箱、平台無時限）。我們的現實：
agent 有平台時限（~58 分背景、codex 一次性）、session 會凍死（Elsa 9/27 十二小時實錄）、
午夜重啟。⇒ 不造不死的跑者，造不失真的交接——把「長跑不塌」轉成「交接不失真」，
而交接是我們最熟的動作（handoff 文化）。副產物：棒次制天然全程留痕（vs 黑箱）。

## §2 架構

```
主人（睡前）──裁【預裁分支樹】──▶ 夜間接力
  棒k（agent 1-2h）─狀態檔─▶ 棒k+1 ─▶ …
     │每棒開頭：讀 state.json（樹/里程碑/預算帳/試過清單）
     │每棒結尾：更新狀態檔＋一段 progress.md（為什麼選這條）
  喚棒＝機械（systemd timer 或上一棒排下一棒）⛔ 不靠誰記得
  S5 審計：小模型（sonnet）每棒間快審三問；大模型每三棒深審方向
  F5 ③生理哨兵照掛真跑；⓪①②④照 F5 鏈
```

## §3 夜間決策權（主人 2026-09-28 問「誰決定繼續什麼」的答案）

- **預裁分支樹**：主人睡前裁的不是每個決定、是樹（3-5 分支＋各分支的預算；先例=
  9/27 J-signal 樹「成立⇒蒸餾／不成立⇒v3」、9/28 晨照樹走零漂移）。
- 樹內：執行細節棒內裁（lead 級判斷由棒 agent 帶 lead 的授權範圍）。
- **樹外＝停棒**：遇到樹上沒有的情況→停、留單、等主人醒。停是預設安全行為——
  寧可少跑三小時不亂跑三小時。
- 契約四條=樹外硬邊界（見 §4）。

## §4 防退化契約（四條；三條半機械執法＋半條 S5 判斷執法）

1. **里程碑階梯**：工單給二元可判的 M1→M2→…（⛔ 不給「繼續改進 X」型方向）。
   夜裡自主性=選怎麼爬，不是選爬哪座山。〔執法：狀態檔核對、機械〕
2. **加密度算力上限 ≤20%〔拍〕**：重複/加 seed/加劑量點的算力佔比；超了自動停棒
   回報。seed 數預算化（判準需要幾顆預先寫死）。〔執法：預算帳欄位、機械〕
3. **新知識心跳**：每棒答「這棒知道了什麼【新的】」。〔執法：S5 審計官判真偽——
   唯一機械管不了的格；連續兩棒無真新知識=停棒〕
4. **死路規則**：失敗是資訊、但同一死路重試 ≤2 次；試過清單是狀態檔必要欄。
   〔執法：清單比對、機械〕

## §4.5 推進引擎（主人 2026-09-28 問「如何確保有推進」的答案；審計是剎車、這節是引擎）

- **棒的預設任務=推里程碑一格**（收割→判讀→按樹發下一批），⛔ 不是守望。每棒交接
  時 state.json 的 milestones 欄必須有變化，或寫明「推不動因為在等 job X」。推不動
  又沒在等東西=STAGNATION 訊號（審計官抓）。
- **深審官的產出義務**：發現樹快走完/收益遞減 ⇒ 備好「明早呈主人的新樹草稿」材料
  （夜裡⛔不開新方向、但醒來即裁即跑、不空轉）。

## §5 S5 審計分層（主人 2026-09-28 裁）

- 快審（sonnet、每棒間、~5 分）：三問——真新知識還是舊結論加密？預算帳對得上？
  重走死路沒？→ PROGRESS-OK / STAGNATION(停棒留單)。
- 深審（opus 或 astra、每三棒、~15 分）：方向審——這條線整體還在樹的意圖上嗎、
  出現「該建議主人轉向」的證據沒？→ 深審報告入狀態檔、醒來呈主人。
- 快審擋加密度、深審擋慢性跑偏。

## §5.5 多機資源分配（主人 2026-09-28 問「如何不讓機器整夜閒置」的答案）

- **樹的每個分支帶資源標籤**（哪型卡/幾張/預估時長）⇒ 裁樹=同時裁「夜裡每台機器
  在幹嘛」的分配表（呈裁模板含此表）。
- 主線分支先佔位；閒置機器跑**候補佇列**——按三軸自評分數排序的次優實驗，⛔ 只收
  「獨立、不等主線結果」的（依賴主線的白跑）。
- ⭐ 張力明寫：目標=**填滿判決力、不是填滿機器**。佇列無判決力>0 的活時寧可空卡，
  ⛔ 不准為避免閒置跑加密度（9/6「不要原地驗證」的夜間版）。好樹＋候補佇列自然
  填到七八成。

## §6 狀態檔 schema（基建 1；接力與午夜重啟共用）

`data/fleet-runs/<戰役>/state.json`：
```json
{"campaign":"", "tree":{"branches":[{"cond":"","action":"","budget":""}]},
 "milestones":[{"id":"M1","desc":"","status":"pending|done|blocked","evidence":""}],
 "budget":{"total_gpu_h":0,"density_gpu_h":0,"density_cap":0.2},
 "tried":[{"path":"","attempts":0,"verdict":""}],
 "batons":[{"k":1,"agent":"","started":"","ended":"","new_knowledge":"","audit":"OK|STAGNATION"}],
 "pending_for_master":[]}
```
progress.md=自由體（為什麼），state.json=機械可判（是什麼）。⛔ 只記做了什麼的
狀態檔會被明天的自己補反理由——兩檔並存是 handoff 血淚的直接移植。
